## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- npm (comes with Node.js) or any package manager of your choice

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/RajputSivam/Habbit-Tracker.git

# 2. Go into the project folder
cd Habbit-Tracker

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Then open the URL shown in your terminal (usually `http://localhost:5173`) in your browser. 🎉

### Build for Production

```bash
npm run build      # Creates an optimized build in the dist/ folder
npm run preview    # Preview the production build locally
```

## 📖 How to Use

1. **➕ Add a habit**: Click **"Add Habit"** and give it a name.
2. **✅ Check it off**: Tap the habit each day when you complete it.
3. **🔥 Track your streak**: Watch your consistency grow day by day.
4. **📊 Review your progress**: Use the progress and calendar views to spot patterns and improve.

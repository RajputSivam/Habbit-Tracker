# 🎯 Habbit Tracker

> Build better habits, one day at a time.

Habbit Tracker is a simple and clean app that helps you build consistency, track your daily routines, and visualize your progress. Set your habits, check them off every day, and watch your streaks grow.

---

## ✨ Features

- ✅ **Daily check-ins**: Mark habits as done with a single click
- 🔥 **Streak tracking**: Keep your momentum going and see your longest streaks
- 📊 **Progress overview**: Visualize completion rates over time
- ➕ **Custom habits**: Create, edit, and delete habits anytime
- 🗓️ **Calendar view**: Review your history at a glance
- 💾 **Persistent data**: Your progress is saved and ready when you come back

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend / Storage:** Local storage (or your preferred database)

---

## 🚀 Getting Started

### Prerequisites

- A modern web browser, or
- Node.js (if you are running a local server)

### Installation

```bash
# Clone the repository
git clone https://github.com/RajputSivam/Habbit-Tracker.git

# Go into the project folder
cd Habbit-Tracker

# Open index.html in your browser
# or run a local server, for example:
npx serve .
```

---

## 📖 How to Use

1. **Add a habit**: Click "Add Habit" and give it a name.
2. **Check it off**: Tap the habit each day when you complete it.
3. **Track your streak**: Watch your progress grow over time.
4. **Review**: Use the progress view to spot patterns and improve.
